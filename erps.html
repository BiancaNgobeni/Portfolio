Project Background

The Educational Reporting System was developed as part of our final-year Information Systems capstone project at the University of Cape Town. Our sponsor was the Western Cape Government's Department of Social Development.

The project focused on educational reporting within juvenile facilities, where educators and administrators need to manage student information, capture assessment marks and produce academic reports.

02

The Problem

A reporting process dependent on manual work.

Educational information was being managed through spreadsheets and separate documents. Capturing marks, calculating results and compiling reports required repetitive manual effort.

This created opportunities for errors, inconsistent reporting and difficulties keeping information organised and accessible.

PROJECT OBJECTIVE

Develop a centralised reporting system that reduces manual work, improves information management and makes academic reporting more efficient.

03

Our Solution

Our team developed ERPS, a web-based application that brings educational administration, mark capture and reporting into one system.

The system was designed around different user responsibilities, with role-based access and features intended to make everyday tasks easier for educators and administrative staff.

07

Technology Stack

The application was developed using Blazor Server and C#, with SQL Server for database management and Entity Framework Core for data access.

Microsoft Entra ID authentication and role-based authorisation were used to support controlled access to system functionality.
